# Pivot Implementation Plan

Goal: Independent offline Android calculator and quiz for linear independence and matrix rank.
Architecture: Android Studio Java shell serving bundled HTML/CSS/JS; exact rational arithmetic for finite numeric inputs.
Tech stack: Java 17, Android WebView, JavaScript safe-integer fractions, CSS animations.

- [x] Test and implement rational row reduction, determinant, pivot columns and a nontrivial null vector.
- [x] Build responsive Solve, Practice and Learn screens with navy/lime design, animated transitions and reduced motion.
- [x] Create Android project and custom icon; build debug APK and run appropriate checks.
- [x] Review completed implementation and save the independent project.

Scope: Numeric entries (integers, decimals, fractions), matrices up to 5 by 5. Each column is one vector. Based on pages 1-3 of the supplied PDF. No symbolic equation parser. Quiz answers computed by the same tested engine. Name Pivot is provisional.

Ruling: Android 9 emulator WebView does not parse BigInt literals. Fraction arithmetic now rejects unsafe intermediate integers instead of rounding. The PDF examples, 625 small 2x2 cases and UI flows pass.
