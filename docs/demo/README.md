# Pivot showcase media

The repository README now shows the refreshed Pivot 0.1.5 interface and app icon.

- `pivot-showcase-v0.1.5.mp4`: 22-second H.264/AAC showcase, 1080 × 1920, 30 fps, 660 frames, with music and subtle interaction sounds.
- `pivot-preview-v0.1.5.gif`: full animated README preview, 270 × 480, 6 fps.
- `pivot-showcase-v0.1.5.jpg`: the settled rank-3 result, also baked into the MP4's first frame as its cover.
- `share-copy.txt`: the accompanying share caption.

Created with the brag skill and Hyperframes from actual Pivot app screenshots. The video shows the supplied course example with rank 3 and determinant −24, successive row operations, correct practice feedback and the original Linear independence lesson. Montserrat and the new palette match the app; no personal phone overlays appear in the video.
