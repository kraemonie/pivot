YOUR POCKET FIELD GUIDE

Three ideas. Everything connects.

01

Linear independence

A set of vectors is independent when the only solution of c₁v₁ + ⋯ + cₙvₙ = 0 has every coefficient equal to zero.

If a nonzero set of coefficients works, the vectors are dependent. A zero vector always makes a set dependent.

02

Rank counts independent columns

The rank is the largest number of independent columns in a matrix. It cannot exceed the number of rows or columns.

All columns are independent exactly when rank = number of columns. A zero matrix has rank 0.

03

Pivots reveal the answer

Swap rows, scale a row by a nonzero number, or add a multiple of one row to another. These operations preserve rank.

Reduce to echelon form and count the pivots. Reduced row-echelon form is useful, but not required to find rank.

The determinant shortcut

For a square matrix only: a nonzero determinant means its columns are independent. A zero determinant means they are dependent. For a rectangular matrix, use pivots and rank.

Reference: Module 2, “Basis, Dimension and Rank of a Matrix,” pages 1–3, supplied course PDF. Pivot focuses on linear independence and rank. It works offline with numeric matrices up to 5 × 5.
